# Frontend

Клиент базы стандартов: React, TypeScript, MUI, Vite, TanStack Query и axios.

## Запуск

```bash
cd frontend
npm ci
npm run dev
```

Версия Node — из `frontend/.nvmrc`, dev-сервер поднимается на `http://localhost:5173`.

| Команда                | Что делает                 |
| ---------------------- | -------------------------- |
| `npm run dev`          | dev-сервер                 |
| `npm run build`        | проверка типов и сборка    |
| `npm run format`       | Prettier: исправляет файлы |
| `npm run format:check` | Prettier: только проверка  |
| `npm run lint`         | ESLint                     |
| `npm run typecheck`    | проверка типов TypeScript  |
| `npm run structure`    | проверка структуры папок   |

Переменные в `frontend/.env` (файл не коммитится, пример — `.env.example`):

```
HOST=localhost
API_PROXY_TARGET=localhost
```

`API_PROXY_TARGET` — хост backend без схемы и порта. Vite проксирует `/api` на `http://<хост>:8000`, убирая префикс `/api`; сам backend слушает 8000.

## Взаимодействие с API

- `src/utils/api/client.ts`: axios-клиент с `baseURL: '/api'`, общий `refreshPromise` и конвертация snake_case → camelCase для ответов.
- Access-токен хранится только в памяти (`tokenStore.ts`), refresh — в cookie. При 401 на `/users/me` делается один refresh, при 403 — logout.
- `authApi.getCurrentUser` приводит бэкендовое поле `avatar` (base64) к фронтовому `avatarUrl` (`data:image/jpeg;base64,...`).
- `cardsApi` содержит список, категории, создание, импорт PPTX и экспорт PPTX со скачиванием файла.

## Экраны и сценарии

- `/login`, `/register` — вход и OTP-подтверждение; после успеха переход на `/base`.
- `/base` — карточки с фильтрами и бесконечной прокруткой. Клик по строке/карточке **не** открывает карточку. Длинные UUID в таблице обрезаются многоточием, полный ID показывается в `Tooltip` при наведении или фокусе.
- `/moderation` — страница «Согласование» только для роли `admin`. Переключатель `PageHeaderTabs` ведёт между вкладками «Карточки» и «Пользователи». Пока страница работает на мок-данных: «Принять» и «Отклонить» меняют локальный список и показывают Toast, backend не подключён.
- Кебаб-меню строки: «Предпросмотр» открывает `CardPreviewModal` (обложка, «Было → Стало», отрасль, поток, мероприятия), «Экспортировать карточку» скачивает PPTX.
- Кнопка «Импортировать» открывает `ImportCardModal`: PPTX, категория, видимость.
- «Создать» открывает `AddCardModal` с секциями «Основное», «Показатели», «Мероприятия» и «Обложка». Заголовок и категория стоят в одной строке, длинные поля растут по высоте. У текстовых полей мягкие лимиты (120/60/80/300 символов) и счётчик при фокусе или заполнении. При невалидной отправке показывается warning-Toast со списком полей, фокус переходит к первой ошибке; при успехе — success-Toast.
- Toast-уведомления показываются без кнопки закрытия, автоматически скрываются через 3 секунды, появляются сверху вниз и имеют скругление 8px. Одновременно виден один тост, остальные ждут в очереди.
- Кнопки создания и импорта доступны ролям `author`/`admin`; пункт «Согласование» виден только роли `admin`.

Общие сценарии и известные ограничения — в [корневом README](../../README.md).

## Проверки и хуки

Перед коммитом: структура, Prettier и ESLint по изменённым файлам `frontend/`. Перед push: структура, Prettier, ESLint и типы по всему `frontend/`. CI повторяет эти шаги и добавляет `npm run build`.
